How to use

  1. (Optional) Enable encryption to secure your API keys with a master password.
  2. Get an OpenRouter API key from openrouter.ai/keys.
  3. Enter your API key and select your preferred AI model.
  4. (Optional) Add a GitHub token for private repos and higher rate limits.
  5. Navigate to any GitHub Pull Request.
  6. Click the "AI Review" button in the PR header.
  7. Wait for the AI-generated review to appear.
